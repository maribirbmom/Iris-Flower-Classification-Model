# 🌸 Iris Flower Classification

A simple machine learning project using the **K-Nearest Neighbors (KNN)** algorithm to classify iris flower species based on their **petal** and **sepal** dimensions.

---

## 📊 Dataset

This project uses the [Iris dataset](https://archive.ics.uci.edu/ml/datasets/iris), a classic dataset in pattern recognition.

Each sample contains:
- Sepal length
- Sepal width
- Petal length
- Petal width
- Species (Setosa, Versicolor, or Virginica)

---

## 🔍 What’s Inside

- Data preprocessing with **Pandas**
- Data visualization using **Seaborn** & **Matplotlib**
- KNN model training & evaluation using **scikit-learn**
- Accuracy & classification report
- Custom prediction with sample inputs
